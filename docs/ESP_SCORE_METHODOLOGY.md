# ESP SCORE METHODOLOGY

## Metodología oficial de valoración de ElectroSpainPro

**Versión:** 1.0  
**Estado:** Metodología oficial  
**Última revisión:** 2026-08-31

---

# 1. Objetivo

El ESP Score es el sistema propio de valoración editorial de ElectroSpainPro.

Su objetivo es proporcionar una valoración estructurada, transparente y reproducible de productos relacionados con:

- Electricidad
- Telecomunicaciones
- Fotovoltaica
- Instrumentación
- Herramientas
- Seguridad
- Equipamiento profesional

El ESP Score está diseñado principalmente desde la perspectiva del profesional que instala, utiliza, mantiene o compra equipamiento técnico.

La puntuación no pretende sustituir:

- Las especificaciones oficiales.
- Las normas aplicables.
- Las certificaciones.
- La documentación técnica.
- Las instrucciones del fabricante.
- La valoración profesional necesaria para cada instalación.

---

# 2. Principio fundamental

El ESP Score evalúa el producto concreto y no la reputación de la marca.

Una marca reconocida no recibe automáticamente una puntuación elevada.

La valoración debe seguir siempre esta cadena:

> Producto → evidencia → análisis editorial → puntuación.

La reputación de una marca puede utilizarse como contexto, pero nunca será suficiente por sí sola para justificar una puntuación.

---

# 3. Estructura del ESP Score

El ESP Score utiliza siete criterios:

| Criterio | Peso |
|---|---:|
| Calidad | 20 % |
| Fiabilidad | 20 % |
| Relación calidad/precio | 15 % |
| Facilidad de instalación | 10 % |
| Durabilidad | 15 % |
| Disponibilidad | 10 % |
| Garantía | 10 % |
| **Total** | **100 %** |

La puntuación de cada criterio se expresa de 0 a 10.

---

# 4. Fórmula

La puntuación global se calcula mediante una media ponderada:

```text
ESP Score =
Calidad × 0,20
+ Fiabilidad × 0,20
+ Relación calidad/precio × 0,15
+ Instalación × 0,10
+ Durabilidad × 0,15
+ Disponibilidad × 0,10
+ Garantía × 0,10
